# 📈 Daily ATH Stock Emailer

월~금 미국(S&P 500)·한국(KOSPI/KOSDAQ) 장 결과의 52주 신고가 종목을 **화~토요일 오전 7시(KST)**에 이메일로 자동 발송하는 GitHub Actions 자동화입니다. 일요일과 월요일에는 예약 발송하지 않습니다.

---

## 📁 파일 구조

```
daily-ath-emailer/
├── .github/
│   └── workflows/
│       └── daily_ath_email.yml   ← GitHub Actions 스케줄러
├── src/
│   └── main.py                   ← 핵심 Python 스크립트
├── requirements.txt
└── README.md
```

---

## 🚀 설정 방법 (4단계)

### STEP 1 — 이 저장소를 GitHub에 올리기

```bash
# 새 GitHub 저장소 생성 후:
git init
git add .
git commit -m "init: daily ATH emailer"
git remote add origin https://github.com/YOUR_USERNAME/daily-ath-emailer.git
git push -u origin main
```

---

### STEP 2 — Gmail 앱 비밀번호 발급

> 일반 Gmail 비밀번호가 아닌 **앱 비밀번호** 를 사용해야 함.

1. [Google 계정 보안 설정](https://myaccount.google.com/security) 접속
2. **2단계 인증** 활성화 (이미 된 경우 스킵)
3. **앱 비밀번호** 메뉴 접속
4. 앱: `메일`, 기기: `기타(직접 입력)` → `ATH Emailer` 입력
5. 생성된 **16자리 비밀번호** 복사해 보관

---

### STEP 3 — GitHub Secrets 등록

GitHub 저장소 → **Settings → Secrets and variables → Actions → New repository secret**

| Secret 이름          | 값 예시                          | 설명                   |
|---------------------|----------------------------------|------------------------|
| `GMAIL_USER`        | `yourname@gmail.com`             | 발신 Gmail 주소        |
| `GMAIL_APP_PASSWORD`| `abcd efgh ijkl mnop`            | STEP 2에서 발급한 앱 비밀번호 |
| `RECIPIENT_EMAIL`   | `ykhan@dacpole.com`              | 수신 이메일 주소       |

---

### STEP 4 — GitHub Actions 활성화

1. 저장소 상단 **Actions** 탭 클릭
2. `I understand my workflows, go ahead and enable them` 클릭
3. 왼쪽 `📈 Daily ATH Stock Email` 선택
4. **Run workflow** 버튼으로 즉시 테스트 실행 가능

---

## ⏰ 실행 스케줄

| 항목        | 내용                           |
|------------|-------------------------------|
| 실행 시각   | 매일 오전 7:00 KST             |
| 실행 요일   | 화 ~ 토 (일·월요일 발송 없음, 휴장일에는 최근 거래일 기준) |
| GitHub cron | `0 22 * * 1-5` (UTC 월~금 → KST 화~토) |

GitHub Actions 예약은 화~토요일 오전 7시(KST) 실행을 요청합니다. 월요일 장 결과는 화요일 아침, 금요일 장 결과는 토요일 아침에 발송합니다. 일요일과 월요일에는 예약 발송하지 않습니다. GitHub 실행 대기열에 따라 시작과 이메일 도착이 늦어질 수 있으며 정확한 시각의 배달을 보장하지는 않습니다.

종목 수가 많아 본문이 길어져도 모든 종목을 그대로 발송합니다. Gmail에서 본문 끝이 접힐 가능성이 있는 큰 리포트에는 국기와 전체 표를 포함한 `ath-full-report.html` 파일을 함께 첨부합니다. 본문 크기만으로 발송을 중단하거나 종목을 삭제하지 않습니다. 데이터·링크·글꼴 검증과 실제 SMTP 용량 제한은 계속 적용합니다.

## ❓ 자주 발생하는 오류

| 오류 메시지                       | 원인 & 해결                                      |
|----------------------------------|------------------------------------------------|
| `SMTPAuthenticationError`        | 앱 비밀번호 오류 → STEP 2 재발급                  |
| `No module named 'yfinance'`     | `pip install -r requirements.txt` 재실행         |
| 이메일은 왔는데 종목 0개          | 주말 또는 공휴일로 시장 데이터 없음 (정상)         |
| Actions 탭에 워크플로우 안 보임   | STEP 4의 활성화 버튼 클릭 필요                    |


종목 수는 상단 한국·미국 합계, 신규 등장 한국·미국 합계, 국가별 표 설명에 `한국 11종목( 4종목 주식, 7종목 ETF )` 형식으로 표시합니다. 주식·ETF 구분은 각 목록의 실제 종목 유형에서 매번 계산하며, 신규 등장 수는 신규 목록만 별도로 집계합니다. 신규 등장 한국·미국 종목을 각각의 표로 나누며, No.는 국가별로 1부터 실제 종목 수까지 매깁니다. 신규 등장 종목명 열은 이전의 약 절반 너비로 표시합니다.

모든 표의 열 제목은 가운데 정렬하고, 모든 열은 한 줄 말줄임표(`…`)로 표시합니다. 마우스를 올리면 전체 값을 확인할 수 있습니다. 종목명 바로 옆에 ETF의 간략한 추종지수·투자분야를 표시하며, 시총·AUM 열은 주식·신규 표 84px, ETF 비교 표 96px로 넓히고 각 열 사이에 검은 구분선을 표시합니다.

ETF 비교 표는 연평균 누적수익률 내림차순으로 최대 100개를 표시합니다. 누적수익률 오른쪽에 **최초주가**, **최근주가**를 표시하며, 보이는 가격은 소수점 이하를 생략하고 천 단위 쉼표를 표시합니다. 두 가격에 마우스를 올리면 소수점을 포함한 정확한 원값·실제 기준일·통화·조정 기준을 확인할 수 있습니다. 누적수익률은 `(최근 가격 ÷ 최초 가격 - 1) × 100`, 연평균 누적수익률은 `[(최근 가격 ÷ 최초 가격)^(1/누적연수) - 1] × 100`입니다. 누적연수는 이 두 실제 가격 날짜 사이의 일수 ÷ 365.25이며, 반올림 전 값으로 계산하고 정렬합니다.

**연초** 열은 1년 왼쪽에 표시하며, 개별 ETF의 실제 수익률 기준일이 속한 해의 전년도 마지막 거래일 가격 대비 누적수익률입니다. **1년·3년·5년·10년**은 각 기간 전체의 단순 누적수익률 `(최근 가격 ÷ 기간 시작 가격 - 1) × 100`을 표시합니다. 예를 들어 3년간 가격이 100에서 200이 되면 3년 열에는 100.0%를 표시합니다. 기간 시작 가격은 실제 수익률 기준일에서 해당 연수만큼 앞선 날짜(윤년 2월 29일의 전년 기준은 2월 28일) 또는 그 이전의 가장 최근 유효한 시세를 사용합니다. 필요한 시작 가격이 없으면 `-`로 표시하며, 상장 이후 수익률로 대체하지 않습니다. 각 기간의 정확한 시작·종료일과 가격은 마우스를 올려 확인할 수 있고 검증 파일에도 저장합니다.

설립 이후 복리 연환산 수익률의 열 제목은 **연평균**이며 계산 방식과 내림차순 정렬은 유지합니다. **설립·상장일**과 **수익률 기준일**은 가운데 정렬하고, 이 세 열은 제목에 맞춰 너비를 줄여 표시합니다.

DFAC는 최초 ETF 상장일 **2021-06-14**를 사용하며, 그 이전 전신 펀드 가격을 ETF 수익률에 섞지 않습니다. **2026-10-02**는 이후 재편 기준일이므로 최초 상장일로 표시하지 않습니다. [운용사 최초 상장 발표](https://www.dimensional.com/us-en/newsroom/dimensional-lists-four-new-etfs-following-the-industrys-largest-mutual-fund-to-etf-conversion), [SEC 재편 공시](https://www.sec.gov/Archives/edgar/data/355437/000207184426001054/dfaidg497.htm)

설립일 당시 가격을 확보하지 못한 경우 실제 최초 확보일 가격을 표시하고, 설립일 출처가 모순되거나 없으면 미확인으로 표시합니다. 미국은 Yahoo 제공 수정주가(auto_adjust)를 사용합니다. 한국도 날짜와 이력이 일치하는 Yahoo 수정주가를 우선 시도하며, 확보할 수 없으면 네이버 차트 종가(배당조정 미확인)를 사용한다고 명시합니다. 서로 다른 가격 기준을 섞어 누적수익률을 계산하지 않습니다.

연평균 누적수익률은 누적수익률을 연수로 나눈 단순 평균이 아니라 복리로 환산한 CAGR입니다. 누적 154.5%는 원금 100이 254.5가 된 뜻이며, 그 원금과 수익이 함께 재투자된다고 가정한 연 수익률을 구합니다.

메일의 한국·미국 시장 기준일과 수집한 모든 ETF의 실제 시세 종료일을 준비 단계와 발송 직전에 대조합니다. 당일 시세가 없으면 해당 종목을 재조회하고, 그래도 확보되지 않으면 전날·전전날 등 가장 최근의 유효한 과거 시세로 모든 수익률을 계산해 발송합니다. 기존 자료보다 오래된 재조회 결과로 되돌리지 않으며, 기준일 이후의 장중 시세를 사용하거나 과거 가격의 날짜를 당일로 바꾸지 않습니다. 가격 이력이 전혀 없으면 후보 종목은 유지하고 계산할 수 없는 값은 미확인으로 처리합니다. ETF 표의 **누적연수 바로 오른쪽 ‘수익률 기준일’**에 실제 계산 종료일을 `26-10-28` 형식으로 표시하고, 마우스를 올리면 전체 날짜를 확인할 수 있습니다. 국가별 시장 기준일과 개별 ETF의 실제 수익률 기준일은 구분해 표시합니다. 전체 ETF의 날짜·정확 가격·과거 시세 사용 상태는 `market-date-proof.json`으로 보관하고 화면 검증 결과의 해시와 대조합니다.
